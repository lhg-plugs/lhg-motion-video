# /lhg-motion-video:audit —— 成片体检

用户输入在 `$ARGUMENTS` 中：`[影片目录] [--fix]`。目录缺省为当前目录。

## 流程（加载 lhg-mv-deliver 第 5 节全程指导）

### 1. 跑脚本
```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/motion_audit.py --target <影片目录> --format text
```
记下 blocker / warning / nit 的数量与明细（含文件、行号、规则说明）。

### 2. 分级与修复
- blocker：逐条修。`--fix` 缺省即自动修（最小改动原则）；修一条用脚本复查一条。
- 修不掉的（如需重渲染、重找音乐版权）→ 列入"需人工处理"，不许为清零改规则。
- warning：修掉或写豁免理由（+有效期）；nit：顺手修。

### 3. 人工评审（脚本覆盖不到的）
- 视觉：探针静帧与成片一致、转场不闪（抽看转场前后 5 帧）、字幕无遮挡
- 听画：转场音效落在拍点上（±0.1s）、音乐高潮对上视觉高潮
- 诚实：画面里的数据/功能是真实的，示意数据标了"示意"
- 导出：手机/电脑实际播放一次，确认无偏色、无黑屏开头

### 4. 输出报告
按 lhg-mv-deliver 第 6 节模板输出自查报告，存为 `docs/audit-YYYYMMDD.md`，结论写清"可发布 / 不可发布"。

## 硬规则
- 有 blocker 就说"可发布" → 不许。
- 为清零改脚本规则或阈值 → 这是作弊，不许。
- 没实际播放过成片不许说"成片没问题"。
