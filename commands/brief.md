# /lhg-motion-video:brief —— 导演 brief

用户输入在 `$ARGUMENTS` 中：`[需求一句话]`。本命令只产出 brief.md，不写渲染代码。

## 流程（加载 lhg-mv-brief）

### 1. 需求澄清（5 问）
1. 这条片子给谁看？（受众）
2. 在哪投放？（平台决定画幅与时长）
3. 看完希望观众做什么？（行动目标）
4. 风格关键词 3 个？（如"深色/科技/克制"）
5. 有无品牌规范（色/字/Logo）？

### 2. 分镜
- 按"预备 → 冲击 → 回稳"三段式排场景：开场 10% 建场、中间 70% 给信息、高潮 1 个视觉记忆点、结尾 10% 行动引导。
- 每个场景：一句话描述 + 时长 + 转场方式 + 落在哪一拍。

### 3. 拍点网格
- 定 BPM（如 120），算出每拍秒数；标出关键转场落点（第 8/16/24 拍）。
- 有配音：先定配音时长，再反推场景分配。

### 4. 交付规格
- 分辨率/帧率/时长/字幕有无/导出编码，全部写进 brief，用户拍板。

输出 `brief.md`。拍板前不许进入渲染。

## 硬规则
- 5 问有 1 问答不上 → 标 `[待确认]`，不许编一个填上。
- 拍点网格缺失的 brief 不许拍板。
