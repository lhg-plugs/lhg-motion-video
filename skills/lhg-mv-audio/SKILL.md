# lhg-mv-audio：音乐与音效

> 目标：音乐的高潮和画面的高潮落在同一拍上。
> 核心纪律：**先有拍点网格，再选音乐；音效按峰值对齐，不许凭感觉放。**

## 1. 何时使用

- 选 BGM：按第 3.1 节三选一
- 做混音方案：按第 3.2–3.4 节
- 转场没劲：检查第 3.3 节 SFX 落点
- 导出前：按第 3.5 节响度

## 2. 输入 / 输出

**输入**：brief.md 的拍点网格 + 渲染出的无声成片（或场景时长表）。

**输出**：音乐/SFX/配音三轨清单 + 混音参数 + 响度确认。

## 3. 分步方法论

### 3.1 BGM 三选一（版权是红线）

1. **自制**：哼唱+简单编曲，或用代码合成铺底。独一无二，零版权风险。
2. **已购版权**：买断制曲库，留好授权凭证。
3. **平台免费曲库**：注意授权范围（商用/署名），下载时截图存档。

"网上下载的热歌"不算来源。用了=埋雷，爆了=下架+索赔。

选曲标准：BPM 与拍点网格匹配（优先选，其次才是"好听"）；情绪曲线和"预备→冲击→回稳"同频；前 3 秒有记忆点（短视频划走只给 3 秒）。

### 3.2 拍点对齐：音乐卡点施工法

1. **找能量峰**：用音频工具看波形/能量曲线，标出音乐的高潮点（drop）和重拍位置。
2. **对表**：把音乐峰点和 brief 拍点网格的关键落点对齐——转场切在重拍上，slogan 定格在 drop 上。
3. **错开 1 秒=白做**：人耳对"音画错位"极敏感，±0.1 秒是及格线。对不齐就换 BGM，别硬凑。

### 3.3 SFX：按峰值对齐

- 转场 whoosh、点击、弹出音效，放在转场**峰值**处（动画速度最快的那一帧），不是转场开始处。
- 音量：SFX 比 BGM 高 3–6dB，比人声（配音）低 3dB——音效是调料，不是主菜。
- 密度：30 秒片子 SFX 不超过 8 个，多了像游戏厅。

### 3.4 三轨混音

| 轨 | 内容 | 音量关系 |
|---|---|---|
| 配音（如有） | 人声 | 最优先，始终清晰 |
| SFX | 转场/强调音效 | 比配音低 3dB |
| BGM | 音乐铺底 | 配音进来时 ducking 压低 6–10dB |

ducking 纪律：有人声时音乐自动让路，没人声时音乐回来。整轨一个音量=外行。

### 3.5 响度：-14 LUFS

- 短视频/流媒体平台惯例目标 **-14 LUFS**（播客是 -16，别混）。
- 流程：三轨混音 → 响度归一到 -14 LUFS → 限幅防削波（峰值 -1dBTP）。
- 偏离太多会被平台二次归一化，压得忽大忽小——所以按标准交，别"我觉得够响了"。

### 3.6 配音专项：有旁白的片子

1. **先写配音稿**：按分镜写，每句标时长。中文常速约 0.3 秒/字，60 秒片子配音稿约 180–200 字。
2. **配音定稿再锁分镜**：配音时长变了，场景分配跟着变。顺序是"稿→音→画"，不是"画→音"。
3. **对齐**：配音每句话的落点进拍点网格；关键句（如价格）落在重拍上。
4. **录制**：参考播客录制指引（小房间、离嘴 20cm、-16 LUFS 录制电平），别在配音上省。

### 3.7 混音检查单（导出前逐项打勾）

- [ ] 三轨音量关系：配音 > SFX（低 3dB）> BGM（ducking 后）
- [ ] ducking：有人声处音乐压低 6–10dB，无人声处回升
- [ ] SFX 密度：30 秒片子≤8 个，全部落在转场峰值 ±0.1s
- [ ] 响度表确认 -14 LUFS，峰值不超过 -1dBTP
- [ ] 开头 3 秒+结尾 3 秒单独听：无爆音、无突兀切断
- [ ] BGM 授权凭证已存档（截图/购买记录）

### 3.8 一句话速查（贴显示器上）

| 环节 | 一句话 |
|---|---|
| 选曲 | BPM 先对上拍点网格，好听其次 |
| 卡点 | 转场切在重拍上，slogan 定格在 drop 上，误差正负 0.1 秒 |
| SFX | 落在转场峰值处，30 秒片子不超过 8 个 |
| 混音 | 配音最优先，SFX 低 3dB，BGM ducking 压 6 到 10dB |
| 响度 | 交 -14 LUFS，不是凭感觉 |
| 版权 | 自制 / 已购 / 免费曲库三选一，凭证存档 |

## 4. 反模式

- ❌ 先选好听的 BGM 再凑拍点——顺序反了，卡点永远对不齐
- ❌ 热歌直接用——版权雷，爆了整条片子下架
- ❌ SFX 凭感觉放——放 10 个不如 1 个落在峰值上
- ❌ BGM 全程一个音量——配音被音乐盖住，观众只记住"吵"
- ❌ 响度凭耳朵——按 -14 LUFS 交，这是标准不是审美

## 5. 常见问题

**Q：找不到 BPM 合适的免费 BGM？**
A：两个办法：用变速不变调工具微调 BPM（±5 以内听不出）；或重排拍点网格去迁就 BGM。别硬卡。

**Q：没有配音，纯音乐+字幕？**
A：可以，字幕就是配音。字幕节奏按"每秒 4–5 个字"排，和拍点网格对齐检查一遍。

**Q：SFX 免费来源？**
A：和 BGM 同样三选一。注意：很多"免费音效包"禁商用，下载页截图存档。

**Q：混音软件有推荐吗？**
A：不绑定具体软件，认准：多轨、能看波形、支持响度归一化到 LUFS。先用免费软件跑通。

**Q：客户坚持要用某首流行歌？**
A：把风险写进 brief 待确认清单：下架加索赔是客户担。字写下来，他多半就换了。

**Q：片子 15 秒，还要拍点网格吗？**
A：要。15 秒 30 拍（120BPM），网格更密。越短的片子越经不起错位。

**Q：纯字幕无配音，节奏怎么定？**
A：字幕就是配音。每秒 4 到 5 个字排时长，关键句落在重拍。先排字幕时间轴，再对动画。

**Q：导出后发现音乐比画面短一截？**
A：BGM 长度不够就循环铺底（找循环点）或换长版本，别拉伸变调。混音时先定音乐总长，再定 -shortest 策略。

## 6. 自检与反馈

混音方案完成自检：

1. BGM 来源三选一明确且有凭证吗？
2. 音乐峰点和拍点网格关键落点对齐了吗（±0.1s）？
3. SFX 落在转场峰值处吗？密度≤8 个/30 秒吗？
4. ducking 做了吗？响度 -14 LUFS 确认了吗？

标准冒烟用例：给定一段 120BPM BGM 描述+分镜表，检查输出是否包含峰点对齐表、三轨音量关系、响度目标。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-motion-video/issues，正文写清"输入 → 错误输出 → 期望输出"。
